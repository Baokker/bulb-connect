# bulb-connect

一个连灯泡益智小游戏。旋转线材和灯泡，让电源点亮所有灯泡。

在线试玩：http://baokker-blog.top/bulb-connect/

## 功能特性

- **四档难度**：简单 5×5 / 中等 6×6 / 困难 7×7 / 地狱 9×9
- **计时挑战**：点击「开始游戏」后计时，完成后显示用时
- **星级评定**：每档难度设两个时间阈值，3★ / 2★ / 1★
- **超时可继续**：超过阈值不锁定，完成后给出实际用时和对应星级
- **显示答案**：双击确认后展示正确连接方式（不计星级）
- **重置确认**：双击确认后恢复本局初始布局
- **可解保证**：生成器先构造覆盖全盘的生成树，再随机旋转打乱

## 技术栈

- React 18 + TypeScript + Vite
- Vitest + React Testing Library（TDD，75 个测试）
- SVG 绘制棋盘，无图片资源
- GitHub Actions 自动构建 + 部署到 GitHub Pages

```bash
npm run typecheck # TypeScript 类型检查
npm run build     # 生产构建（输出到 dist/）
npm run preview   # 本地预览生产构建
```

## 游戏规则

- 每局一个电源（不可旋转）、若干灯泡、其余为线材（直线/弯线/T 形/十字形）。
- 点击「开始游戏」后启用旋转并开始计时。
- 点击格子顺时针旋转 90°（十字形旋转后接口不变）。
- 相邻两格需面对面接口同时存在才导通。
- 所有灯泡点亮即胜利；未通电的线材不阻止胜利。
- 生成器先构造覆盖全盘的生成树（保证可解），再随机旋转打乱。

## 星级阈值

| 难度 | 棋盘 | 灯泡数 | 3★ | 2★ |
|------|------|--------|-----|-----|
| 简单 | 5×5 | 5 | ≤60秒 | ≤120秒 |
| 中等 | 6×6 | 6 | ≤120秒 | ≤240秒 |
| 困难 | 7×7 | 7 | ≤180秒 | ≤360秒 |
| 地狱 | 9×9 | 9 | ≤300秒 | ≤600秒 |

## 项目结构

```
src/
├── game/
│   ├── types.ts          # 核心类型、难度配置、星级计算
│   ├── directions.ts     # 方向、相反方向、顺时针旋转
│   ├── power.ts          # 通电遍历（BFS）与胜利判定
│   ├── generator.ts      # 生成树、解状态、打乱（支持任意尺寸）
│   └── gameReducer.ts    # 旋转/重置/新游戏/开始/完成/显示答案
├── components/
│   ├── Board.tsx         # 响应式棋盘
│   ├── Tile.tsx          # 单格 SVG 渲染
│   ├── GameControls.tsx  # 难度选择/开始/计时/新游戏/重置/显示答案
│   └── ConfirmDialog.tsx # 通用确认弹窗
├── App.tsx               # 组装与状态（计时器、弹窗、星级）
├── main.tsx
└── test-utils.ts         # 测试用确定性随机数
```
